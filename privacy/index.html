About this website

Last updated 19 November 2026

This website does not use cookies, analytics, advertising, or third-party scripts or fonts.

It consists of a few static pages. Each app has its own privacy policy: Quillway · Evenpitch.

Hosting

The site is hosted on GitHub Pages. Like any web host, GitHub receives your IP address when you load a page and may keep it in server logs for security. We do not have access to those logs. The domain name yujona.com is managed through Cloudflare, which answers the lookups that point your browser to GitHub; it does not serve or see the pages. See GitHub's privacy statement.

Email

Email links open your own email app. If you write to us, your message is used only to reply.
